# nimnote — รู้ก่อนขาย รู้ก่อนรับซื้อ

> ปรัชญาโต้ง: ปัญหาฐานรากของธุรกิจรับซื้อของเก่า = **ประเมินราคาไม่ได้ เพราะไม่รู้ว่าของชิ้นนั้นข้างในมีอะไร**
> → nimnote คือ "จอบ" ที่ขายให้คนขุดทุกคน: **ฐานความรู้ "ของชิ้นนี้ ข้างในมีอะไร + เกรด + ราคาอ้างอิง"**

## ลูกค้าที่แท้จริง
| ใคร | ปัญหา | nimnote ช่วยอะไร |
|---|---|---|
| คนรับซื้อของเก่า | ประเมินราคาไม่ได้ เพราะไม่รู้องค์ประกอบ | บอกข้างในมีอะไร + เกรด (g/t) + ราคาอ้างอิง |
| ผู้ใช้ทั่วไป | อยากรู้ของเก่าพังๆ คุ้มค่าขายไหม | พิมพ์ชื่อ → รู้ว่าคุ้มไหมก่อนเอาไปขาย |

## ข้อมูลอ้างอิง (ตัวเลขจริง)
- PCB โทรศัพท์มือถือ: Au 350 g/t, Ag 2640 ppm, Cu 13%, Pd 119 ppm (Sahan 2019, EPA 2018)
- PCB คอมพิวเตอร์: Au 250 g/t, Cu 20% (Hagelüken)
- ทองคำใน e-waste สูงกว่าแร่ 100-800 เท่า
- เครื่องซักผ้า/ตู้เย็น: เหล็ก + ทองแดง (motor/wiring) + คอมเพรสเซอร์มีทองแดง
- สายไฟ: ทองแดงแกนใน (bare bright สุดค่า)
