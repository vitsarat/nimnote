# nimnote — ฐานรากความจำสำหรับ AI ของคุณ (shovel, not gold)

> คนส่วนใหญ่วิ่งไปแข่งทำ "ปลายทาง" (แชทฉลาดๆ เหมือน NotebookLM) —
> แต่โอกาสที่แท้จริงคือ **ฐานรากที่ทุกปลายทางต้องพิง**: ข้อมูลที่จัดโครงสร้าง + เก็บส่วนตัว + เชื่อมโยงกัน
>
> nimnote คือ **"จอบ"** ไม่ใช่ "ทอง" — ขายให้คนขุดทุกคน ไม่ผูกข้างใด

## 3 เสาหลัก (ทำไมถึงเป็นฐานราก)
1. **ฐานความรู้ส่วนตัว** — เอกสารของคุณ อยู่บนเครื่อง ไม่รั่วไหล (localStorage / ภายหลัง JSON offline)
2. **ความจำเชื่อมโยง (linked memory)** — ผูกแหล่งข้อมูล/โน้ตเข้าด้วยกันแบบมีประเภท (supports / contradicts / related / derived) แล้วขยายบริบทผ่านกราฟ
3. **ส่งออกให้ AI ตัวไหนก็ได้** — ได้ prompt พร้อมอ้างอิง ไปวางใน LLM ที่คุณใช้ (ไม่ผูก OpenAI/คลาวด์ใด)

## ต่างจาก NotebookLM / ChatPDF อย่างไร
| เขา | nimnote |
|---|---|
| ออนไลน์ ข้อมูลขึ้นคลาวด์ | ออฟไลน์ / ส่วนตัว |
| ผูก LLM ของเขา | ส่งออกให้ LLM ตัวไหนก็ได้ |
| ไม่โฟกัสไทย | ไทยทำงาน (Thai bigram) |
| เป็น "ปลายทาง" (แชท) | เป็น "ฐานราก" (ความจำ/ข้อมูล) |
