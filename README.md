# nimnote อุดร — รู้ก่อนขาย รู้ก่อนรับซื้อ

> ปรัชญาโต้ง: ปัญหาฐานรากของธุรกิจรับซื้อของเก่า = **ประเมินราคาไม่ได้ เพราะไม่รู้ว่าของชิ้นนั้นข้างในมีอะไร**
> กรอบโต้ง: เครื่องมือตัวกลาง (two-sided) สำหรับ จ.อุดรธานี — เชื่อม **ร้านรับซื้อ** กับ **ผู้ขาย**

## ใครใช้ (two-sided)
| ฝั่ง | ปัญหา | nimnote ช่วยอะไร |
|---|---|---|
| ร้านรับซื้อของเก่า (อุดร) | ประเมินราคาไม่ได้ เพราะไม่รู้องค์ประกอบ | ใช้ฐานร่วม → ประเมินราคาแม่นขึ้น แข่งได้ |
| ผู้ขายทั่วไป (อุดร) | ถูกกดราคา เพราะไม่รู้ของข้างในมีอะไร | รู้คุ้มค่าก่อนเอาไปขาย → ต่อรองได้ |

→ **ราคาโปร่งใสทั้งสองฝั่ง** = มูลค่าที่ไม่มีใครในพื้นที่ทำ
